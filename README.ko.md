Reweave는 내가 선택한 ChatGPT·Claude 대화를 검색하고 연결해 두는 Windows 로컬 앱입니다.
지난달에 내린 결정을 찾아보고, 그 근거가 된 대화를 확인하고, 필요한 맥락을 새 대화에
넣을 수 있습니다. 새 채팅을 열 때마다 배경부터 다시 설명하는 수고를 줄이려는 도구입니다.

대화는 쓰던 ChatGPT나 Claude에서 이어가세요. Reweave는 그 사이의 맥락을 보관합니다.

![대화 요약, 결정, 열린 질문, 원문 근거 링크가 보이는 Reweave 홈 화면](docs/verification/2026-09-10/browser-qa-home-1280-after.png)

*실행 중인 앱에서 예시 데이터로 캡처한 Reading Room 화면입니다.
앱의 화면 언어는 현재 영어입니다.*

## 이런 상황에 쓸 수 있어요

AI와 함께 정한 방향, 작업 중 얻은 교훈, 어떤 선택을 했던 이유는 채팅 기록 속에
묻히기 쉽습니다. Reweave는 다음 대화에서 다시 쓸 수 있도록 그 내용을 정리해 둡니다.

| 이럴 때 | 이렇게 활용할 수 있습니다 |
| --- | --- |
| 한동안 쉬었던 프로젝트를 다시 시작할 때 | 이전 결정, 아직 풀지 못한 질문, 다음 할 일을 확인합니다. |
| 다른 AI로 작업을 이어갈 때 | 다음 ChatGPT·Claude 요청에 관련 맥락을 넣습니다. |
| 정리된 내용이 맞는지 확인하고 싶을 때 | 근거가 된 원문 메시지를 열어 확인하고 잘못된 내용을 수정합니다. |
| 아이디어는 기억나는데 어느 대화였는지 모를 때 | 라이브러리 전체를 검색하고 주제·프로젝트 사이의 연결을 따라갑니다. |

## 주요 기능

- **선택한 대화 저장.** ChatGPT·Claude 내보내기 파일을 가져오거나 Chrome·Edge
  확장 프로그램으로 현재 대화를 저장합니다. API 키가 없어도 저장할 수 있습니다.
- **다시 읽기 좋은 정리.** 분석 후 대화 전체를 정리한 **Conversation Brief(대화 요약)**와
  결정·교훈·선호·사실·질문·할 일 등을 담은 **Context Item(맥락 항목)**이 만들어집니다.
  각 항목은 관찰된 내용, 추론, 제안을 구분해서 보여줍니다.
- **원문까지 이어지는 근거.** Home·Explore·Sources에서 내용을 읽고,
  연결된 공간이나 해당 항목의 근거가 된 메시지로 이동합니다.
- **내 컴퓨터에서 검색.** 키워드 검색은 바로 사용할 수 있습니다.
  Smart search를 켜면 기기에서 실행되는 모델로 의미가 비슷한 내용도 찾습니다.
- **필요할 때 맥락 넣기.** **Use Reweave context**를 누르면 허용된 관련 맥락이
  작성 중인 요청 앞에 추가됩니다. 확인하고 전송하는 것은 사용자입니다.
- **수정과 이력 관리.** 항목을 수정하고 되돌리거나, 공간 이름을 바꾸고 합칠 수 있습니다.
  별도 확인이 필요한 내용은 Review에서 검토합니다.
- **백업과 관계 탐색.** 비밀번호로 암호화한 백업을 만들고 복원할 수 있습니다.
  그래프로 연결을 살펴보거나, 공유용으로 가린 이미지를 미리 보고 내보낼 수 있습니다.

## 빠른 시작

**현재 배포 상태:** Reweave는 개발 중입니다. 2026년 9월 11일 기준으로 GitHub에
공개된 릴리스는 없습니다. 아래 방법으로 소스에서 실행할 수 있으며, Windows 패키지도
로컬에서 만들 수 있습니다. 현재 설치 파일에는 코드 서명이 없습니다.

### Windows에서 소스로 실행하기

**Git**, **Python 3.11 이상**, [**uv**](https://docs.astral.sh/uv/getting-started/installation/),
**Node.js 22.12 이상과 npm**이 필요합니다. 데스크톱 창은 Microsoft Edge WebView2를 사용합니다.

PowerShell에서 다음 명령을 차례로 실행하세요.

```powershell
git clone https://github.com/seolbbb/reweave.git
cd reweave
uv sync --locked
cd frontend
npm ci
npm run build
cd ..
uv run reweave desktop
```

데스크톱 앱이 열리면 첫 안내에서 기존 대화를 가져오거나 건너뛰고 빈 라이브러리로
시작할 수 있습니다. **AI 제공자를 연결하기 전에도 가져오기·탐색·검색은 가능합니다.**

개인 대화 없이 먼저 살펴보려면 **Import conversations**에서 저장소에 포함된
[`tests/fixtures/chatgpt_sample.json`](tests/fixtures/chatgpt_sample.json)을 가져오세요.
원문 메시지는 곧바로 검색할 수 있습니다. 대화 요약과 맥락 항목이 만들어지려면 분석이 필요합니다.

로컬 브라우저 화면으로 쓰고 싶다면 프런트엔드 빌드 후 다음 명령을 실행하세요.

```powershell
uv run reweave app --db ./reweave.db
```

[http://127.0.0.1:8765](http://127.0.0.1:8765)를 열면 됩니다. 사용을 마치면
터미널에서 `Ctrl+C`로 서버를 종료하세요. 이 명령은 현재 폴더의 데이터베이스를 사용하며,
데스크톱 앱의 기본 저장 위치와 다릅니다. 확장 프로그램은 데스크톱 실행 방식이 필요합니다.
실행 방식을 바꾸기 전에 [라이브러리 저장 위치](#라이브러리는-어디에-저장되나요)를 확인하세요.

### Windows 실행 파일 만들기

위의 소스 설치와 프런트엔드 빌드를 마친 다음, 저장소 최상위 폴더에서 실행하세요.

```powershell
.venv\Scripts\pyinstaller.exe --noconfirm --clean packaging\Reweave.spec
.\dist\Reweave\Reweave.exe
```

실행 파일이 다른 번들 파일을 함께 사용하므로 `dist\Reweave` 폴더 전체를 보관하세요.
이 번들을 실행하는 컴퓨터에는 Python이나 Node.js를 따로 설치할 필요가 없습니다.

사용자별 설치 파일을 만들려면 [Windows 패키징 가이드](packaging/installer/README.md#repeating-the-build)를
따르세요. `dist\Reweave-Setup.exe`와 파일 해시가 담긴 매니페스트가 생성됩니다.
설치 파일에 확장 프로그램이 포함되지만, 브라우저에 설치하고 연결하는 단계는 직접 진행합니다.

## 처음으로 대화를 저장하고 다시 활용하기

```text
대화 선택 → 저장 또는 가져오기 → 분석 → 내용과 근거 확인 → 새 요청에 맥락 추가
             로컬에 저장       BYOK     로컬 라이브러리      전송은 직접
```

### 1. 대화 가져오기

**Import conversations**에서 지원되는 `.json` 또는 `.zip` 내보내기 파일을 선택하세요.
다시 읽고 싶은 대화 몇 개로 시작해도 되고, 전체 내보내기 파일로 과거 기록을 채워도 됩니다.
같은 대화를 다시 가져오거나 저장하면 변경된 내용을 갱신하며, 동일한 내용은 중복 저장하지 않습니다.

지원 형식은 ChatGPT의 `conversations.json`, Claude 대화 JSON,
그리고 이 파일들이 담긴 ZIP입니다. ZIP 안에서는 지원되는 JSON만 읽으며,
첨부 파일이나 다른 형식의 파일은 가져오지 않습니다. 일반 PDF·메모·웹페이지나
다른 채팅 서비스의 대화는 현재 가져오기 대상이 아닙니다.

평소 브라우저에서 대화할 때는 아래의 확장 프로그램 설정을 마친 뒤
**Save current conversation**을 누르면 됩니다. AI의 응답이 끝난 다음 저장하세요.

### 2. 준비가 되면 AI 분석 연결하기

**Settings**에서 제공자를 선택하고 API 키를 연결한 뒤 사용 가능한 모델을 고르세요.
OpenAI, Anthropic, Google Gemini, OpenRouter, OpenAI 호환 엔드포인트를 설정할 수 있습니다.
호환 엔드포인트에는 base URL도 필요합니다. 대화한 AI와 분석에 쓰는 제공자가 달라도 됩니다.

**BYOK**는 *Bring Your Own Key*, 즉 본인의 API 키를 연결하는 방식입니다.
Reweave는 선택한 대화 내용을 해당 제공자에게 직접 보내 분석하며, 제공자의 API 요금이
발생할 수 있습니다. 활성 제공자를 연결하면 대기 중인 분석이 자동으로 시작될 수 있으므로,
먼저 분석 대기 목록과 [데이터 전송 범위](#개인정보와-데이터)를 확인하세요.

Context activity에서 진행 상태, 일시 중지·재시도, 일일 요청·토큰 한도를 확인할 수 있습니다.
이 한도는 사용량을 제한하는 장치이며 정확한 금액 기준의 지출 상한은 아닙니다.
긴 대화는 이어서 처리할 수 있도록 나누어 분석하고, 미완료 상태는 화면에 표시합니다.

### 3. 읽고, 근거를 확인하고, 수정하기

**Home**에서 정리된 내용을 읽거나 **Explore**에서 프로젝트와 주제를 따라가세요.
**Read context & sources**, **View source**로 근거가 된 대화를 확인할 수 있습니다.
내용이나 적용 범위가 잘못됐다면 수정하세요. 변경 이력이 남고 되돌릴 수 있습니다.
대화에 따라 개별 맥락 항목 없이 대화 요약만 만들어지는 것도 정상입니다.

### 4. 다음 대화에 맥락 넣기

Reweave를 실행한 상태에서 지원되는 ChatGPT·Claude 대화에 요청을 작성한 뒤,
확장 프로그램을 열고 **Use Reweave context**를 누르세요.

처음에는 사용 목적과 범위를 선택한 다음 **Use**를 다시 누릅니다.
Private에서는 여러 공간의 관련된 일반 맥락을 활용할 수 있고,
Work·Client·Shared에서는 허용할 범위를 지정해야 합니다.
민감한 맥락은 별도 미리보기와 확인이 필요합니다. 선택한 범위는 해당 대화에 대해 기억합니다.

작성 중인 요청 앞에 추가된 내용을 검토하고 준비가 되면 직접 전송하세요.
기존 초안은 유지되며, 나중에 Use를 다시 누르면 이전 Reweave 블록을 교체합니다.
**Use는 현재 대화를 저장하거나 전송 버튼을 누르지 않습니다.**

### Chrome·Edge 확장 프로그램 설정하기

1. [Windows 실행 파일을 빌드](#windows-실행-파일-만들기)해 `ReweaveNativeHost.exe`를 준비합니다.
2. `chrome://extensions` 또는 `edge://extensions`를 열고 **개발자 모드**를 켭니다.
   **압축해제된 확장 프로그램을 로드합니다**를 선택해 이 저장소의 `extension` 폴더를 불러옵니다.
3. 브라우저에 표시된 확장 프로그램 ID를 복사합니다.
4. 저장소 최상위 폴더에서 아래 명령의 ID를 바꿔 실행합니다.
   Edge를 사용한다면 `-Browser Edge`로 바꾸세요.

```powershell
.\scripts\register_native_host.ps1 -ExtensionId 'YOUR_32_CHARACTER_EXTENSION_ID' -Browser Chrome
```

5. `.\dist\Reweave\Reweave.exe`를 실행한 뒤 ChatGPT·Claude 대화에서 확장 프로그램을 엽니다.
   단축키를 바꾸지 않았다면 Windows에서 `Alt+Shift+R`로도 같은 팝업을 열 수 있습니다.

등록 스크립트는 현재 Windows 사용자의 Native Messaging 설정을 통해 확장 프로그램과
로컬 앱을 연결합니다. 로컬 주소나 토큰을 따로 복사할 필요는 없습니다.
설치 파일로 설치했다면 경로가 다르므로
[설치된 확장 프로그램 연결 안내](packaging/installer/README.md#browser-extension-an-explicit-second-step)를 따르세요.
권한과 세부 동작은 [확장 프로그램 가이드](extension/README.md)에서 확인할 수 있습니다.

## 개인정보와 데이터

| 동작 | 데이터 처리 방식 |
| --- | --- |
| 저장·가져오기 | 선택한 대화를 분석 전에 로컬에 저장합니다. 대화를 수동 조작 없이 상시 수집하지 않습니다. |
| 탐색·검색 | 검색은 로컬에서 실행됩니다. Smart search를 켜면 모델을 다운로드한 뒤 로컬에서 임베딩을 만듭니다. |
| AI 분석 | 선택한 대화가 본인이 지정한 BYOK 제공자에게 직접 전송됩니다. 관계 분석에는 범위가 맞는 기존 요약 일부가 함께 전송될 수 있습니다. |
| Use | 현재 대화와 초안은 검색을 위해 로컬에서 처리하며 저장하지 않습니다. 입력창에 들어간 맥락은 전송 버튼을 누르기 전에도 해당 웹페이지에서 접근할 수 있습니다. |
| 백업 | 비밀번호로 암호화한 `.reweave` 파일에 라이브러리와 설정을 담습니다. API 키는 제외하며, 복원 후 제공자를 다시 연결해야 합니다. |
| 공유·진단 | 직접 내보내기를 실행합니다. 그래프는 가린 결과를 미리 보여주고, 진단 파일에는 대화 본문과 인증 정보를 넣지 않습니다. 다른 곳에 게시하는 것은 별도 선택입니다. |

Settings에서 연결한 API 키는 운영체제의 자격 증명 저장소에 보관합니다.
**사용 중인 SQLite 라이브러리 자체는 저장 시 암호화되지 않습니다.
백업을 암호화해도 원본 데이터베이스가 암호화되는 것은 아닙니다.**
원본 대화를 지워도 파생된 맥락과 보관된 근거는 남으므로, 함께 지우려면 별도로 삭제해야 합니다.

로컬 저장과 로컬 AI 분석은 다릅니다. 민감한 맥락을 Use에 넣을 때 받는 확인은
재사용 범위를 위한 것이며, 분석 대상으로 선택한 대화에서 민감한 부분을 자동으로
가려 주지는 않습니다. 전체 처리 방식은
[개인정보·지원 가이드](docs/release/PRIVACY_AND_SUPPORT.md)를 참고하세요.

## 자주 묻는 질문과 문제 해결

### API 키나 Reweave 계정이 필요한가요?

Reweave 계정은 필요 없습니다. 저장·가져오기·탐색·키워드 검색은 키 없이 쓸 수 있습니다.
대화 요약과 맥락 항목을 만들려면 분석 제공자를 연결해야 합니다.
선택 기능인 로컬 Smart search는 모델 다운로드가 필요하지만 API 키는 필요 없습니다.

### 라이브러리는 어디에 저장되나요?

데스크톱 기본 경로는 `%LOCALAPPDATA%\Reweave`이며, CLI와 `reweave app`의
기본 데이터베이스는 `./reweave.db`입니다. `--db` 또는 `REWEAVE_DB`로
데이터베이스를 지정하고, `REWEAVE_DATA_DIR`로 데스크톱 데이터·설정·모델 폴더를
옮길 수 있습니다. 하나의 라이브러리는 한 번에 하나의 앱 또는 CLI 프로세스만 사용할 수 있습니다.
예시는 [설정 안내](docs/DEVELOPMENT.md#configuration)에 있습니다.

### 분석이 대기 중이거나 Home이 비어 있어요

Context activity에서 활성 제공자, 일시 중지 여부, 일일 한도, 다음 재시도 시간을
확인하세요. 분석이 끝나기 전에도 저장한 대화는 **Sources**와 검색에서 볼 수 있습니다.
실패한 분석을 재시도하거나 Sources에서 **Analyze**를 선택할 수 있습니다.

### 확장 프로그램에서 Reweave를 열라고 나와요

데스크톱 앱을 실행하고, 등록한 Native Host 경로·브라우저·확장 프로그램 ID가
맞는지 확인하세요. 확장 프로그램을 불러오는 것만으로는 연결이 끝나지 않습니다.
지원되는 대화가 완전히 열린 상태에서 AI의 응답이 끝난 뒤 다시 시도하세요.

### 다른 기기와 동기화하거나 다른 플랫폼에서 쓸 수 있나요?

현재 데스크톱 대상은 Windows이고, 확장 프로그램은 Chrome·Edge에서
ChatGPT·Claude를 지원합니다. 계정 기반 동기화, macOS, 추가 채팅 서비스,
팀 라이브러리는 현재 출시 범위에 포함되지 않습니다. 암호화 백업으로 라이브러리를
옮길 수는 있습니다. 앱 UI는 영어이며, 이 README는 한국어로도 제공합니다.

## 현재 개발 상태

Reading Room, Save·Use, 맥락 연결, 수정, 검색, 그래프, 암호화 백업·복원은
구현되어 격리된 환경에서 검증한 기록이 있습니다. 실제 사용자의 일상 사용 검증,
Windows의 일반 파일 저장 대화상자 확인, 공개 배포는 아직 남아 있습니다.
화면 캡처나 자동 테스트만으로 실제 유용성이 입증된 것은 아닙니다.

현재 근거는 [Project Status](docs/PROJECT_STATUS.md), 남은 작업은
[Roadmap](docs/ROADMAP.md), 의도한 제품 동작은
[Product Spec](docs/PRODUCT_SPEC.md)에서 확인할 수 있습니다. 상세 개발 문서는 영어입니다.
