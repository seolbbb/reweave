## Cross-cutting checks

- All model requests use explicit source content and scope-compatible bounded summaries;
  personal instructions cannot bypass the extraction schema, cited evidence or routing checks.
- Independent reviews cover provider consent lifetime, per-key allowance accounting, restore
  usage preservation, process/CLI ownership, archive identity and scope-aware reconciliation.
- A's shared tokens, offline typography, keyboard focus, narrow layouts and reduced motion are
  covered by frontend/browser evidence. Actual native 200% zoom remains unexercised; equivalent
  640x360 layout reflow passed and is not labeled a native zoom test.
- Installer filesystem isolation and actual EXE process behavior are separate. Silent isolated
  install/uninstall does not prove visible Windows dialogs, browser registration or signed release.
- No paid model call, real conversation transmission, credential export, automatic browser
  registration, public posting or external deployment is authorized or claimed by this matrix.

Exact final test counts, artifact hashes and integration tips belong in the final verification
record and Project Status, so this mapping does not turn an earlier build into current evidence.
