# Prepared owner acceptance

TASK-012 remains mandatory. Synthetic fixtures prove software paths, not personal usefulness.
Run this only after the final executable and installer evidence are available. Do not infer
approval to read an existing private archive, transmit it, use paid credentials or operate the
owner's active desktop from this checklist.

## Inputs requiring the owner's choice

- One specific conversation or export to use, with any portions explicitly excluded.
- The provider and model, maximum provider attempts, maximum currency spend, and stop rule.
- Whether the owner will operate the native app/browser or separately authorize assistance.

Before transmission, calculate the chosen source's estimate locally, check the provider's current
official pricing, and choose the smaller permitted attempt/spending bound. Begin with one source
and one enabled credential. Automatic analysis of unrelated queued sources must be paused or
isolated. No retries outside the agreed ceiling; stop on uncertain source scope, unexpected cost,
failed grounding or a limit response. Never include conversation text or secrets in the report.

## Minimal complete round-trip

1. Install the verified package and open Reweave. Confirm the Reading Room is usable. If using
   web Save/Use, load the included extension and register only its exact displayed ID as described
   in the installed instructions. No automatic submission or Save is enabled by registration.
2. Import or explicitly Save the selected conversation. Verify it is searchable before analysis.
   Connect the approved provider and run only the selected source within the agreed limits.
3. Read the Brief and one useful item, compare its source excerpt, and correct/undo if needed.
   Close and restart the app; verify the source, item and any correction survived.
4. Write a normal draft in the next supported ChatGPT/Claude conversation. Choose Use, confirm the
   intended destination, and inspect the inserted context. Verify the original draft remains and
   no message is submitted. Repeat Use once if within scope to check replacement without duplication.
5. Save one encrypted backup through the native Save File dialog. Verify Graph PNG/diagnostic file
   saving and 200% zoom while operating the native app. A synthetic or separate test Library should
   be used for destructive restore/deletion checks; the owner's active Library need not be replaced.

Record only whether the source was faithful, what information was useful or missing, whether less
explanation was repeated, actual latency/usage, and any scope or interaction failure. The owner
decides usefulness. A positive process test alone does not close the Goal or the graph discovery gate.

Public v1 scope freeze, synchronization timing, signing and public/store publication remain explicit
owner decisions. Repository integration and a local installer do not authorize public distribution.
